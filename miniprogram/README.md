# 小羊三消微信小程序

这是一个无需后端的本地小游戏原型，玩法类似“羊了个羊”的三消核心：点开未被遮住的牌，凑齐三个相同图案自动消除；暂存槽最多 7 格，格子满了就失败，全部牌消除即通关。

## 导入微信开发者工具

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录（能看到 `project.config.json` 的目录）。
3. AppID 先选“测试号”或填入你自己的小程序 AppID；正式预览和发布需要绑定你自己的 AppID。
4. 点击“编译”，在模拟器或手机预览。

进入 `miniprogram/pages/game/game.js` 可以调整图案、牌面数量、槽位数量和关卡逻辑。当前所有资源都用 Emoji 和 WXSS 绘制，不需要联网，也没有云函数或数据库。

## 现有限制

这是一个可玩的基础版本，不是完整商业版：没有登录、排行榜、分享奖励、广告、关卡服务器和自定义美术资源。微信开发者工具对 Emoji 的字体显示可能与不同手机略有差异；正式发布前建议替换为自己的 PNG 图标，并在真机上测试触控、层叠和不同屏幕尺寸。
