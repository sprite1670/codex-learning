# 今天谁当家 · 家务抽签

## 安卓安装包

[下载家务抽签 APK（Android 8.0 及以上）](https://github.com/sprite1670/codex-learning/raw/refs/heads/main/downloads/household-lottery-1.0.apk)

在安卓手机上下载后，用文件管理器打开 APK。按手机提示，允许当前浏览器或文件管理器安装此来源的应用，即可安装“家务抽签”。这是个人测试安装包，支持离线使用，不申请网络或存储权限。如果仓库设为私有，请先登录有权限的 GitHub 账号。

打开后可以直接看到人数选择和姓名输入框。选择 1～5 人，依次输入名字、点击抽签即可。点击后播放 5 秒动画，五种结果轮番出现，再揭晓最终分工。动画期间不能重复点击或重新开局，结果揭晓后交给下一位输入。本轮进度保存在手机中。

安装包保存在 [downloads](downloads/)，源码、构建与验证说明见 [android/README.md](android/README.md)。已经验证签名、包内容及内置游戏的浏览器流程；尚未在安卓真机或模拟器上验证安装运行。

## 电脑网页版

用浏览器打开 `index.html` 即可游玩，无需安装、联网或启动服务器。

1. 设置本轮参与人数（1～5 人）。
2. 第一位参与者输入名字，点击“点击抽签”。
3. 五种结果轮番显示 5 秒，然后揭晓抽中的任务。
4. 下一位直接在姓名框中输入名字，继续抽签。
5. 所有人抽完后，下方显示本轮分工。点击“重新开局”并确认即可开始新一轮。

签池固定为：刷碗、扫地、沏茶、做饭、玩。每次从剩余结果中等概率选择一个，各结果最多出现一次；少于 5 人时会有未被抽中的结果。

同一轮在同一浏览器页面中轮流操作，每人使用固定名字。同名不可重复抽签，重名的人可加编号；本地游戏没有身份认证，无法识别更换名字的同一人，也不支持多设备同步。浏览器允许本地存储时，刷新会保留进度；动画期间刷新也不会重新抽签或提前展示结果。清除浏览器数据、移动文件或切换浏览器可能丢失记录。

所有样式、逻辑和图标均在单个 HTML 文件内，不依赖外部资源。姓名仅存储在当前浏览器中。
